# salesforce-ai-inspection-automation
AI-enabled inspection and support automation system using Salesforce Flow and Prompt Builder.

## Project Objective

The objective of this project is to automate inspection documentation and reduce manual effort using Salesforce AI capabilities.

## Technologies Used

* Salesforce Platform
* Salesforce Flow
* Salesforce Prompt Builder
* Lightning App Builder
* Custom Objects and Fields
* Validation Rules and Field-Level Security

## Key Features

1. Create and manage inspection records.
2. Store inspection dates, statuses, and inspector information.
3. Generate inspection summaries using Salesforce Prompt Builder.
4. Save AI-generated responses in the Inspection Summary field.
5. Trigger summary generation using the Generate Summary button.
6. Customize the user interface using Salesforce Lightning.

## How It Works

1. Open an inspection record in Salesforce.
2. Click the Generate Summary button.
3. The Salesforce Flow invokes the configured prompt.
4. The generated response is saved in the Inspection Summary field.
5. Refresh the record to verify that the summary remains saved.

## Project Testing

The Generate Summary functionality was tested on an existing inspection record. The generated response appeared in the Inspection Summary field and remained saved after refreshing the record.
